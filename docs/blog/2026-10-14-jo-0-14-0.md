# Jo 0.14.0 Released

*October 14, 2026 · The Jo Team*

Jo 0.14.0 is available now. This release makes failures easier to trace:
`abort`, `assert`, and the `...` placeholder include the source file and line
in their messages. You can also use `compile.location` to capture a source
location as a value.

Mutable collections gained a few useful operations. They now provide `isEmpty`,
mutable lists support `push` and `pop`, and `Array.clear` clears an element slot.
The release also improves type-checking errors and pattern coverage, and fixes
code generation and parsing issues across the Python, Ruby, and JavaScript
backends.

Several common operations are faster. Vararg calls with a single splice avoid
an unnecessary copy, string comparison and trimming use faster runtime
implementations, and Python and Ruby use native array construction for
`Array.fill`.

There are source compatibility changes to check when upgrading. Calls that
previously relied on implicit nullary thunk adaptation now need an explicit
`() => expression`. `Option.getOrElse` and `Result.getOrElse` now take an ordinary
default value, and string line splitting has new behavior for empty input and
trailing separators. Precompiled libraries must be rebuilt for the new SAST
format.

See the [full changelog](https://github.com/typescope/jo/blob/main/CHANGELOG.md#0140---2026-10-13)
for the complete changes and upgrade notes. To get the release, follow the
[install guide](../usage/install.md).
